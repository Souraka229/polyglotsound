# PolyglotSound (démo CPU gratuite)

Adaptation musicale fon / français / anglais : traduction chantable, notée sur 9 critères musicaux,
puis chantée sur la mélodie originale et mixée sur l'instrumental d'origine.

- Traitez un **extrait de 20 s** : sur ce matériel gratuit (CPU), comptez 5 à 10 min par extrait.
- La voix de cet aperçu est **synthétique** (expérimentale). La version « voix d'origine »
  (Seed-VC) et l'IA locale demandent un GPU : utilisez le notebook Colab du dépôt.
- N'importez que des morceaux dont vous avez les droits. Ne convertissez jamais la voix d'autrui.
